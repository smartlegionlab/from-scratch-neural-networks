How to Use

  1. The dataset is generated automatically on load (~1,900 colors across 12 classes).
  2. Move the R, G, B sliders - the network guesses the color name with a confidence percentage.
  3. Press Auto-gen to regenerate the dataset and Start Training to train.
  4. Watch the loss curve fall and the accuracy rise in panel 3.
  5. Teach the network yourself: pick a color chip below the sliders, then press + Save Sample.
  6. Random throws a random color; try colors that sit between classes (teal, lime, navy).
  7. Export / Import saves and loads the trained brain as a JSON file.

About

RGB Color Name Guesser Neural Network
version 1.0.0

RGB Color Name Guesser Neural Network is a real multilayer perceptron written from scratch in pure JavaScript: 3 inputs (normalized R, G, B) -> 12 sigmoid hidden neurons -> 12 softmax outputs, one per color class (red, orange, yellow, green, cyan, blue, purple, pink, brown, gray, black, white).

Loss: cross-entropy with softmax, trained by mini-batch SGD with momentum (default) or Adam.

The dataset is synthetic: thousands of HSV samples converted to RGB and labeled by a deterministic color rule, so the classes are fuzzy but consistent - exactly what makes color naming interesting for a small network.

Learn color naming the way you learned colors as a child: from many examples. Trained brains can be saved and loaded as JSON.
