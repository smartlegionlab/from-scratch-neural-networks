How to Use

  1. Draw the letter X on the 8×8 grid using your finger or mouse.
  2. Press + This is X - the drawing is saved to the dataset and the grid clears automatically.
  3. Now draw a letter O (a ring near the edges of the cells).
  4. Press + This is O.
  5. Repeat 3-5 times for each letter, varying the size and position.
  6. Press Start Training. Watch the loss graph go down.
  7. Draw any new X or O - the network instantly shows its guess with a confidence percentage.

About

X / O Shape Recognition Neural Network
version 1.3.1

X / O Shape Recognition Neural Network is a real artificial neural network, written from scratch in pure JavaScript - no frameworks, no libraries, no tricks.

Architecture: a multilayer perceptron (MLP) with 64 inputs (one per grid cell), 12 hidden neurons and 2 outputs (X and O). Sigmoid activation, trained by backpropagation with gradient descent.

Everything you see is real: neuron brightness = activation; line thickness = weight magnitude; the loss graph = the true error decreasing as weights update.

Scale-aware rendering: on wide screens all 64 inputs are drawn, on narrow screens every 4th input (16 of 64).

Purpose: an educational demo - to watch live how a handful of numbers reorganize until they recognize your handwriting. Trained brains can be saved and loaded as JSON.
