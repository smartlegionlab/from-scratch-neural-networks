How to Use

  1. Pick a logic function: XOR, AND, OR, NAND, XNOR - switching resets the network, so you train it again from zero.
  2. Play: flip a / b - the answer is green when right, red when wrong, with a confidence bar.
  3. Random / Test all run quick checks; results flash in the toast.
  4. Press Start Training or Fast Learn → 100%. Training auto-stops at 4/4 correct and the weights freeze.
  5. Adjust learning rate (Precise by default) and pick the optimizer (SGD by default, Adam also available).
  6. Export saves the trained brain as JSON; Import loads one back.

Why XOR is special: a single-layer perceptron cannot learn XOR - the hidden layer bends the space; watch the decision map reshape as it learns.

About

Boolean-Logic Neural Network
version 1.2.2

Boolean-Logic Neural Network is a real multilayer perceptron (MLP) written from scratch in pure JavaScript, learning classic Boolean logic with full live visualization.

Architecture: 2 inputs → 3 sigmoid hidden neurons → 1 sigmoid output (> 0.5 = true). Trained by stochastic mini-batch optimization - SGD with momentum (0.9) (default) or Adam. Training auto-stops at 4/4 correct.

Decision map: every pixel feeds continuous (a, b) through the brain and colors it by output - blue = false, red = true.
