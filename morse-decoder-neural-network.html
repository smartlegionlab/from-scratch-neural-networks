How to Use

  1. Press the big dot . and dash - keys (or keyboard A / S) - each press sounds like a real telegraph key.
  2. The network guesses the letter live, with the top 3 candidates in panel 3.
  3. Press Space (or the space bar) to commit the current code into the decoded word.
  4. X deletes the last symbol, C clears everything.
  5. Press Fast Learn - the net memorizes all 36 Morse codes to 100% and stops.
  6. Export / Import saves and loads the trained brain as a JSON file.

About

Morse Decoder Neural Network
version 1.3.1

Morse Decoder Neural Network is a real multilayer perceptron written from scratch in pure JavaScript: 10 inputs (5 Morse slots, each encoded as a dot/dash pair) -> 16 sigmoid hidden neurons -> 36 softmax outputs (A-Z and 0-9).

Loss: cross-entropy with softmax, trained by mini-batch SGD with momentum (default) or Adam. Training stops automatically at 100%.

The dataset is the complete International Morse table, encoded with blank padding, so the network answers live for any dot-dash sequence of up to 5 symbols.

Sound: a native Web Audio engine synthesizes dit, dah and the mechanical key click on every press - no samples, everything generated live.
