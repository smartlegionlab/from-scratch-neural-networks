How to Use

  1. Pick your side: X (first) or O (second).
  2. Click an empty cell - the brain answers once, then the turn returns to you.
  3. Press Fast Learn and let the loss curve fall; each move is logged in the console.
  4. Use Copy in the console (bottom-left) to grab the training and game log.
  5. The brain never loses once trained: it blocks forks and always takes the draw at worst.
  6. Export / Import saves and loads the trained brain as a JSON file.

About

Tic-Tac-Toe Brain Neural Network
version 1.5.0

Tic-Tac-Toe Brain Neural Network is a real multilayer perceptron written from scratch in pure JavaScript: 27 inputs (9 cells, each encoded as X / O / empty) -> 48 sigmoid hidden neurons -> 32 sigmoid hidden neurons -> 9 softmax outputs, one per move.

Teacher: every reachable board position (~4,400 non-terminal) is labeled by a minimax solver, and each position learns a uniform distribution over all its optimal moves. Loss is cross-entropy + softmax with a low learning rate (0.02), gradient clipping and per-epoch weight clipping to stay stable.

Result: once trained, the brain responds optimally from any position on either side - you can beat it only by drawing.

The bottom-left console logs the training (epoch, loss, policy accuracy, forced-win accuracy) and the game (each move with its top-3 candidates) - copy it to debug any issue.
